# Под свечой

Трёхмерный рогалик от первого лица в духе игр PS1. Вы спускаетесь со свечой в катакомбы под старой часовней: десять глубин, от погоста до логова Хранителя. Пока горит свеча, тьма ждёт.

## Как играть

- **В браузере, на компьютере и телефоне:** https://hermeusmora.github.io/pod-svechoy/
  Ничего устанавливать не нужно. На телефоне лучше держать экран горизонтально.
- **Программа для Windows:** скачайте `.exe` из раздела [Релизы](https://github.com/HermeusMora/pod-svechoy/releases) и запустите, установка не нужна.
  Windows может предупредить о неизвестном издателе: нажмите «Подробнее», потом «Выполнить в любом случае».
- **Без интернета:** скачайте файл [`index.html`](index.html) (кнопка «Download raw file») и откройте его в Chrome, Edge или Firefox. Всё вшито в один файл.

Прогресс хранится у вас: в браузере для сайта и файла, в папке пользователя для программы.

## Управление

**Компьютер.** WASD: ходьба, Shift: бег, мышь: обзор, левая кнопка или пробел: удар, Q: умение героя (у Стража щит, также правая кнопка),
E: действие, колесо мыши: выбор предмета, F: применить его, 1–8: быстрое применение, Tab: меню героя, I: сумка, J: дневник, M: карта этажа, Esc: пауза.
F11 или Alt+Enter в программе: полный экран.

**Телефон.** Левый палец: ходьба (у края джойстика бег), правый палец: обзор. Кнопка с мечом: удар, рядом умение героя.
Колесо предметов внизу: край выбирает предмет, середина применяет. «Меню» открывает героя, снаряжение, сумку, навыки и дневник. Нажмите на мини-карту, чтобы открыть карту этажа.
